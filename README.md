### 🚀 Featured projects

#### ⚖️ [AtlasLex — Moroccan Commercial Law RAG](https://github.com/imdataboy/AtlasLex)

A document-grounded legal question-answering application. Users can **add and index their own legal PDFs**, then ask questions in French and review document, article, and page references.

- Extracts and parses PDF content, including article-aware processing for supported legal documents.
- Combines **dense retrieval (Qdrant)** and **BM25**, then applies reciprocal rank fusion and cross-encoder reranking.
- Uses **Gemini** for query rewriting and answers, with source-reference checks.
- Includes a CLI, Docker-based Qdrant setup, and automated tests.

**Stack:** Python · Qdrant · BM25 · Transformers · Gemini · Docker · pytest  
[Explore the repository →](https://github.com/imdataboy/AtlasLex)
